API Key Generator

HOW TO?

Standard flow — Generate then Set

Click Generate to mint a fresh key — the server stores it as primed and shows the plaintext above.
Pass that plaintext to whoever needs to call /api/v1/order (the sender).
Once they have it wired in, enter the admin passcode and click Set — the primed key becomes the active key.

Break-glass flow — Paste your own key

Tick I have my own key if you already hold the plaintext (e.g. you typed it from a CLI elsewhere) and just need online/ to start accepting it.
The textarea unlocks; paste the key, enter the admin passcode, and click Set.
The pasted key is stored and activated directly — the previously-primed key (if any) is unprimed and ignored.

After setting

Every POST /api/v1/order from now on must carry Authorization: Bearer <active-key>.
If a key is lost or compromised, repeat either flow above to rotate. The previous active key is immediately deactivated; in-flight requests using it will start receiving 401.
